# ACTIVELOG 스킨 적용

1. 티스토리 `꾸미기 → 스킨 편집 → HTML 편집`에서 기존 HTML과 CSS를 백업합니다.
2. HTML 탭에는 `skin.html` 전체를 붙여 넣습니다.
3. CSS 탭에는 `style.css` 전체를 붙여 넣습니다.
4. `파일업로드` 탭에서 `images` 폴더의 PNG 4개를 모두 업로드합니다.
5. 미리보기에서 PC와 모바일을 확인한 뒤 `적용`을 누릅니다.

## 꼭 수정할 항목

- 이미지 경로는 `./images/active-log-*.png`로 연결되어 있으므로 파일명은 바꾸지 않습니다.
- `href="#"` 링크는 실제 글·카테고리 링크로 교체해야 합니다.
- 현재 `TRENDING` 및 카테고리별 본문은 HTML에 하드코딩되어 있으므로 자동으로 최신 글이 갱신되지 않습니다.
- 자동 갱신형 메인은 티스토리 `커버` 치환자 구조로 한 차례 더 변경해야 합니다.

## 현재 결과 범위

이 CSS는 전달받은 HTML 클래스에 맞춰 레퍼런스 이미지와 유사한 레이아웃을 만듭니다. 기존 상세 글, 검색, 카테고리 목록은 유지하고 메인 커버 화면의 폭·카드·사이드바·모바일 반응형을 우선 덮어씁니다.
