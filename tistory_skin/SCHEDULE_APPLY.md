# ACTIVELOG 일정 화면 적용

티스토리 관리자에서 `꾸미기 → 스킨 편집 → html 편집`으로 이동합니다.

1. HTML 탭의 내용을 `skin.html` 전체 내용으로 교체합니다.
2. CSS 탭의 내용을 `style.css` 전체 내용으로 교체합니다.
3. 파일업로드 탭에서 아래 PNG 파일 4개를 추가합니다.
   - `active_log/assets/event-cheorwon-dmz-marathon-2026.png`
   - `active_log/assets/event-gongju-baekje-marathon-2026.png`
   - `active_log/assets/event-binggrae-granfondo-2026.png`
   - `active_log/assets/event-andong-maskdance-festival-2026.png`
4. 우측 상단 `적용`을 누릅니다.
5. 블로그 메인의 `일정 전체 보기` 버튼을 눌러 확인합니다.

일정 화면 주소는 `https://active-log.tistory.com/?schedule=1`입니다.

현재 상세 글 연결:

- 철원DMZ 국제평화마라톤: `/7`
- 공주백제마라톤: `/8`
- 빙그레 그란폰도: `/9`
- 안동국제탈춤페스티벌: `/10`

상세 글이 비공개인 동안에는 블로그 관리자만 열 수 있습니다. 공개 전환 후 일반 방문자도 상세 글로 이동할 수 있습니다.
